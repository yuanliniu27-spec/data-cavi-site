Section 09 · Strategy

09产品会议判断：哪些机会值得讨论

将竞品机会、用户真实问题和入口覆盖合并判断。这里不再重复展示机会卡片，只保留产品会需要的结论：证据是否充分、影响多少会话、建议如何处理。

产品机会数据证据会议判断建议方向
默认入口优化18,587 / 18,591（约100%）高优先级。现有词云已覆盖销量榜前三/车型对比，但金融、首付、月供、预算、征信等需求仍需要更细的入口承接。保留“销量榜前三哪个更适合”等已有入口，并细化为Top车型单车金融方案、最低首付、预估月供、征信能否购车、48/72期方案对比等入口。

示例：“最低首付需要多少钱？”；“月收入$25,000，能买哪些车？帮我估首付和月供”
车型 + 金融方案并列对比11,319 / 12,907（87.7%）高优先级。用户大量围绕期限、银行、首付、月供、哪个更好做比较，和金融转化直接相关。把单条回答升级为对比卡：车型参数 + 银行 + 期限 + 首付 + 月供 + 利率并列展示。

示例：“Kia K3、Versa、Aveo 哪个金融方案更适合我？”；“48期和72期，月供和总成本差多少？”
点选式帮选车选车意图 1,831 条消息，对应 1,383 个去重用户；1轮会话占78.0%可推进。需求规模中等，但能解决用户不愿继续补充条件的问题，适合作为首轮承接工具。沿用图中“AI选车”点选方式，用预算、车型、能源、座位数等标签替代打字，形成点选式买车流程。

示例：预算：10万以下 / 10-15万 / 20-30万；车型：轿车 / SUV / MPV；能源：纯电 / 汽油 / 插电混动。
购车转化闭环选车场景车卡触达后真实留资闭环 3 / 1,383（0.2%）；全部卡片触达后真实留资闭环 50 / 11,626（0.4%）需重点讨论。线索表能证明存在真实留资结果，但按“用户意图=选车+车系/车型卡触达”的窄口径看，选车场景到真实留资的可匹配闭环较弱；全卡片口径下，大量留资来自金融意图会话。围绕高意向回答前置报价、库存、WhatsApp入口，并补齐点击、提交、销售跟进数据。

示例：回答金融方案后展示“查看库存/获取报价”；对高意向用户直接引导“发送到 WhatsApp 获取可贷方案”。
市场资讯4 / 12,907（0.0%）暂不作为前台重点。用户消息侧证据弱，不能把 AI 回答中提到的政策/新车当作用户需求。作为后台知识库和销售话术维护，不列为本轮产品重点。

数据口径：会话按会话ID去重；用户按用户身份标识去重（空标识不计入）；时间按墨西哥自然日聚合，原始表内时间字段为 UTC；卡片触达=卡片消息内容非空或卡片推荐类型非空且不为0；车型统计仅从FinanceCard JSON解析。

数据来源：08-17~08-23 沿用当前网页既有统计；08-24~08-30 来自 20260824-20260831_5959.xlsx。GA4、主线索、满意度和推荐方案项粗采纳等核心指标保留上版口径，待补齐新周对应外部表后可重算。

局限性：新周会话日志已按 2026-08-24~08-30 窗口重算，并剔除 2026-08-31；真实留资闭环、AI渗透率、推荐匹配度/采纳率和满意度等核心指标保留上版口径，原因是本次只提供会话 Excel，未提供对应 GA4 与主线索表。
